# Portfolio screenshot capture plan

Use real interfaces and clean demonstration data. Keep desktop screenshots close to 16:10 (for example 1440×900) and mobile screenshots around 390×844. Avoid browser bookmarks, developer tools, personal data, and repetitive dashboard views.

## ScolaPro
1. Hero: authenticated school dashboard with navigation and useful operational context.
2. Attendance or timetable workflow.
3. Report card, learner academic view, or document output.
4. Parent portal or Library / Textbooks.
5. Optional mobile: attendance/offline workflow.

## GovFleet Namibia
1. Hero: strongest fleet dashboard or public Namibia route visual.
2. Transport request detail with approval timeline.

4. Trip Authority PDF preview.
5. Optional mobile: driver logsheet, fuel entry, or inspection.

## Mondesa Health

## Repository image paths

When final screenshots are ready, save optimized WebP files under:

`public/assets/projects/<project-slug>/`

Suggested names:
- `cover.webp`
- `feature-01.webp`
- `feature-02.webp`
- `feature-03.webp`
- `mobile.webp`

Then replace the temporary portfolio placeholder images in `src/lib/portfolio-projects.ts`.
